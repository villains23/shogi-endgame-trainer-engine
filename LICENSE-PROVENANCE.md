## What this does and does not establish

- It is an explicit, public reply by the author, to a direct question about this very file, naming `nn.bin` and GPLv3.
- It is not a license file shipped with the archive, and it is not a signed grant. The official repository
  (<https://github.com/yssaya/AobaNNUE>) is GPL-3.0 (its `Copying.txt` is the GPL v3 text), but the archive on
  Google Drive carries no license text.
- A license note added by the author to the official repository or release would be the strongest form of evidence
  (see `RELEASE-CHECKLIST.md`). This project has not asked for one and does not claim that it exists.
- How far "Corresponding Source" reaches for trained weights is a separate question; see `MODEL.md`.
